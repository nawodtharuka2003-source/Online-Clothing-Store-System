# Online Clothing Store System

A console-based C++ program that simulates an online clothing store.

## Features

- Enter customer name
- Select clothing items and quantities
- Calculate subtotal
- Apply discounts
- Calculate shipping cost
- Select a payment method
- Display the final bill

## Items

| Item | Price (Rs.) |
|---|---:|
| T-Shirt | 1200.00 |
| Jeans | 2500.00 |
| Jacket | 3500.00 |
| Shoes | 4000.00 |

## Discounts

- Rs. 2,000–4,999: 5%
- Rs. 5,000–9,999: 10%
- Rs. 10,000 or more: 15%

## Shipping

- Colombo: Free
- Other cities: Rs. 500.00
